- **Data:** Hugging Face is unreachable from this machine, so `prepare_data.py` ran through a wrapper that only redirected the repo ids to local copies of the same checkpoints (`Qwen3-8B`, `Qwen3-1.7B`, `Qwen3.5-27B`) and their tokenizers. Same c4 text and code path otherwise.
- **`fsdp_fp32_grad`: not run.** It needs 2 GPUs and this machine has 1 (two ranks on one GPU fail: the script selects `cuda:$LOCAL_RANK`).
